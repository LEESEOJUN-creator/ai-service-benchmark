# 구현·검증 구분

최신 현황은 [STATUS](STATUS.md), 재실행은 [RUNBOOK](RUNBOOK.md)을 따른다.

| 구성 | 상태 | 검증 범위 |
|---|---|---|
| 공통 프롬프트 8종 | 최종 버전 고정 | core-v2 동일 UTF-8 입력 3사 실측 |
| 사이트 지침 | 현재 계정 실측 | 모델 선택, PNG/TXT 첨부, 캔버스·원문·비용·다운로드 |
| 엄격 plan | 구현 | 미확정 조건 차단; 브라우저 실행 아님 |
| 실행 저널 | 구현 | 중복·미완료·조건·경로·시간 검증 |
| 날짜 붙은 상세 PDF·XLSX·그래프 PDF | 구현·로컬 검증 | 기준별 근거, 답변 원문, UX, 원화 환산 수식, 질문별 비용·품질·소요시간 선그래프, 보이는 홈 폴더 기본 출력. 실제 기록 재출력은 개인 파일로 검증 |
| 전송/완료 관측 JS | 실사이트·모의 테스트 | 전송 1회, 입력 변경, 중복 및 타임아웃 처리 |
| 개인 최종본 | 재생성·렌더 검증 | 기존 GPT·Claude·Gemini 56개 기록의 원화 PDF·XLSX와 공통 7문항씩의 선그래프 3쪽을 재출력. 다른 사용자 계정 재현은 남음 |
| 객관 검사 | 제한 구현 | 고정 함수·XLSX 검증. 범용 샌드박스 아님. 블라인드 평가 남음 |
| 전체 실측 | 현재 계정 완료 | GPT 24회, Claude 16회, Gemini 16회. Gemini는 승인된 비대칭 설정의 탐색 비교 |
| 독립 무인 실행 | 없음 | Codex의 연결된 브라우저 도구 필요 |

Git에는 코드·공용 지침만 포함한다. 계정·자료·원문·스크린샷·보고서는 Git 제외 경로에 둔다. 공용 질문·설정 파일명에는 실행 날짜를 넣지 않지만 개인 최종 세 파일명에는 생성일을 넣는다.
