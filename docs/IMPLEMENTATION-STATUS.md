# 구현·검증 구분

최신 현황은 [STATUS](STATUS.md), 재실행은 [RUNBOOK](RUNBOOK.md)을 따른다.

| 구성 | 상태 | 검증 범위 |
|---|---|---|
| 공통 프롬프트 8종 | 최종 버전 고정 | core-v2 동일 UTF-8 입력 3사 실측 |
| 사이트 지침 | 현재 계정 실측 | 모델 선택, PNG/TXT 첨부, 캔버스·원문·비용·다운로드 |
| 엄격 plan | 구현 | 미확정 조건 차단; 브라우저 실행 아님 |
| 실행 저널 | 구현 | 중복·미완료·조건·경로·시간 검증 |
| HTML 보고서 | 구현 | 원문 escape, 미확정 구분 |
| 전송/완료 관측 JS | 실사이트·모의 테스트 | 전송 1회, 입력 변경, 중복 및 타임아웃 처리 |
| 최종 GPT XLSX/PDF | 생성·렌더 검증 | 비공개 출력; 공용 자동 exporter는 HTML까지 |
| 객관 검사 | 제한 구현 | 고정 함수·XLSX 검증. 범용 샌드박스 아님. 블라인드 평가 남음 |
| 전체 실측 | 부분 | 최종 GPT 24회. Claude 최종 미실측, Gemini 조건 미확정 |
| 독립 무인 실행 | 없음 | Codex의 연결된 브라우저 도구 필요 |

Git에는 코드·공용 지침만 포함한다. 계정·자료·원문·스크린샷·보고서는 runs/, local/, fixtures/local/에 보관한다. 날짜는 공유 문서·산출물 제목에 넣지 않으며 내부 측정 시각과 질문 데이터 속 일정은 보존한다.
