# 작업 현황

이 문서는 개발 검증과 과거 변경 이력입니다. 실제 실행 순서는 [실행 안내](REPRODUCIBLE-RUN.md)를 따르며, 과거 계정의 승인·설정·실측을 이번 실행의 근거로 재사용하지 않습니다.

## 화면 조작 실수 예방

- 공통 UI 흐름에 현재 URL/대상 확인 → 한 번 조작 → 변경 후 관측을 명시했다. 모든 모델에 적용하며 이웃 메뉴 추측 클릭, 중복/숨김 버튼 강제 선택, 실패 후 연속 클릭을 금지한다. 첫 전송 전 개인화 설정과 원래 값/승인, 첨부 미리보기 대조, 중단 시 설정 복구와 미완료 단계 재개를 정리했다.
- 사이트별로 정확한 MonoGPT 주소·첨부 내용 대조, Timely의 새 대화/첨부 버튼 구분, ChatGPT 모델 하위 메뉴와 문체 메뉴 구분을 보완했다. 해당 단계 실패로 전체 요청을 처음부터 다시 실행하지 않는다.
- 선택적 `browser/ui-actions.mjs`는 현재 origin·새 화면·정확한 대상 1개·가시성·활성 상태·클릭 후 조건을 검사한다. 실패 후 같은 흐름의 추가 클릭을 막으며 자동 재시도하지 않는다. GPT 준비 레시피에 연결했고 현재 URL/최종 선택 확인 콜백을 필수로 했다. 다른 모델의 과거 JS 레시피는 그대로 무관측 실행하지 않도록 한계를 명시했다.
- 검증: Python 70개 + 브라우저 모의 43개(신규 26개) 통과. 잘못된 주소·중복/숨김/비활성 대상·메뉴 전환 실패·유사 모델명·타임아웃·동시 클릭·이미 꺼진 토글·메뉴 자동 닫힘을 포함한다.
- 실제 사이트 재실측은 하지 않았다. 합성 화면 테스트는 현재 계정의 UI 호환성이나 오류 없는 실행을 보증하지 않는다. 개인 결과·실측 중 세션·보고서 형식·질문 구성·비용 정책은 변경하지 않았다.

## 문서 역할과 시작 순서 정리

- README → 시작 프롬프트 → 실행 안내로 진입 경로를 정리했다. 실행 안내는 준비·실측·평가·전달 순서, RUNBOOK은 설정·명령·필드 참고, BROWSER-FLOW는 UI 체크리스트, EXECUTION-RELIABILITY는 추론 예외·선택적 Playwright 참고로 구분했다.
- 기본 CLI 타이머와 선택적 JS 타이머를 혼동하게 하던 문구를 정리했다. 기존 평가 정정 방식과 모델별 승인 범위 설명도 현재 구현에 맞췄다.
- 문서만 수정했다. 파일·폴더 삭제/이름 변경, 측정·보고서 코드, 질문·모델 배분·설정·평가 기준, 개인 보고서·원본 데이터 변경은 없다.
- 검증: 변경 문서의 상대 링크·앵커 42개, diff 공백 검사, Python 70개 및 브라우저 모의 17개 통과. 실제 사이트 요청이나 유료 재실측은 수행하지 않았다.

## 새 세션 공통 실행 경로 고정

- 브라우저 API가 다르다는 이유로 매 실행마다 임시 타이머·기록기를 만들던 경로를 기본 영속 CLI 타이머로 통일했다. reserve 뒤 timer-start, 완료 UI 확인 직후 timer-complete를 기록하면 result에 시간이 자동 병합된다. null 필드로 지워지지 않으며 시작·최초 완료를 재설정하지 않는다. UI 관측은 여전히 에이전트가 수행한다.
- 프로세스별 변수가 모두 사라지는 별도 Python 프로세스 테스트를 추가했다. macOS Python 3.9의 프로세스별 monotonic 기준점 차이를 발견해 시스템 CLOCK_MONOTONIC을 사용하도록 수정했다. 시계 불일치와 완료 관측 누락은 값을 만들지 않고 표시한다. 새 기본 경로는 도구 오버헤드를 포함한 완료 관측 상한이다.
- 답변별 강점·한계·실무 영향·근거와 비교별 공통 충족·차이·보완을 PDF·엑셀에 직접 표시한다. 개인정보 없는 가상 평가 예시를 제공한다. 원문 추출 대조를 기록해 코드 블록 추출 실패를 모델 실패로 혼동하지 않도록 한다.
- audit는 모델 범위·시간·평가·총평·서비스 간 해설·UX의 누락을 찾아 보완 목록을 반환한다. 보고서를 생성하지 못하게 하는 비용 차단이 아니며 재전송을 하지 않는다. 평가 정정은 원문 기록을 덮지 않고 supersedes_sequence와 이유를 추가한다.
- 자동 검증: Python 70개 + 브라우저 모의 17개. 별도 프로세스의 시계→원장→그래프 데이터 연결과 합성 40건(GPT24/Claude8/Gemini8)→6시트 엑셀·상세 PDF·모델별 그래프 PDF 3파일 생성을 포함한다. 합성 40건의 시간 누락 0건, 그래프 8쪽을 확인한다.
- 이 변경에서 실제 유료 UI 요청은 보내지 않는다. 자동/합성 테스트 통과는 새 사용자 계정에서의 40회 실측 성공이나 UI 판정·평가 내용의 정확성을 보장하지 않는다. 기존 개인 보고서와 원시 결과는 수정하지 않는다.

## 시간 누락·Gemini 생략 재발 방지

- 새 세션의 GPT/Claude 32건 결과에서 시간이 전부 누락되고 Gemini 8건이 추론 불일치로 생략된 문제를 확인했다. 실제 데이터는 Git에 포함하지 않는다.
- 기본 실행 정책을 추론 차이만 허용하는 자동 참고 비교로 명시했다. 엄격 전용/의도 불명확이면 한 번 확인하며 질문 없이 모델을 생략하지 않는다. 정책을 init에 고정하고 참고 비교의 추론 차이를 기록 검증에서도 허용한다. 모델·프롬프트·첨부·기타 설정은 임의 변경하지 않는다.
- 클릭 전 시계 영속 저장, 완료 확인 후 시각 측정, 보고서용 시간 필드 자동 변환, 첫 실제 요청 점검을 추가했다. 누락 결과도 보존하지만 status·3종 보고서에서 시간 측정 미완료를 드러낸다. 하한 없는 상한은 유지하며 빈 시간 축/‘미관측초’ 표시를 제거했다.
- 참고 비교는 별도 표시한 비용·품질·시간 요약/그래프를 제공하며 엄격 평균과 합산하지 않는다.
- 새 유료 UI 재실측은 이 코드 변경에 포함하지 않는다. 자동 테스트/출력 검증과 실제 사이트 실측 완료를 구분한다.
- 검증: Python 58개 + 브라우저 모의 17개, 합계 75개 회귀 테스트. 모의 브라우저 시간 필드 → 실행 원장 → XLSX 시간 표시/그래프 데이터 연결을 포함한다. 개인 보고서를 수정하거나 과거 미관측 시간을 채우지 않는다.

## 재현 실행의 출력 결함 수정

- 새 세션의 24건 기록은 GPT만 측정된 실행이었다. 기본 설정이 Claude/Gemini를 비활성화했고, 출력이 기록된 모델만 보여줘 누락이 가려졌다.
- 기본 후보 3개를 활성화하고 GPT 24회 + Claude 8회 + Gemini 8회 = 40회로 질문을 배분했다. 후자 두 모델은 교육·기획·이미지·파일 분석만이며 전체 8문항 완료가 아니다. 첨부 검토·활성화 전 계획 요청 수는 더 작다.
- 시작 시 모델 계획 스냅샷, 후보 ID 연결, 미실측 후보 범위표, 공통 질문 교집합 요약을 추가했다. 기존 계획 없는 기록은 현재 설정 참고로 표시한다.
- PDF·엑셀 앞에 모델별 요약, comparison 이벤트 기반 서비스 간 실제 차이 해설을 추가했다. 막연한 판단·높은 만점 비율은 검토 사항이며 자동 재채점하지 않는다.
- 그래프는 범위표, 모델별 비용·품질과 시간·수치 대조 2페이지, 별도 파일 생성/전환 기능 표로 개선했다. 파일 생성 비용을 선택 모델의 비용 선에 섞지 않는다.
- 개인 24건은 재측정하지 않고 출력 회귀 검증에만 사용한다. Claude/Gemini의 이번 실행 실측은 여전히 없다.
- Python 49개·브라우저 모의 테스트 11개 통과. 실제 24건 기록으로 임시 3파일 재출력, 그래프 4쪽·PDF 모델 요약 및 엑셀 6개 시트의 렌더/수식 캐시를 점검했다. Excel 앱 자체의 재계산은 별도 미검증이다. 개인 원본·계정·검증 출력은 Git에 포함하지 않는다.

## 구현됨

- 공통 8개 항목 각 1개 프롬프트와 모델별 2사/3사 비교 그룹.
- 기본 요청 상한 40회. 한 실행의 예약 상한도 최대 40회이며, 원화 예산·요청당 비용 확인 게이트는 유지한다. 3모델 전체 56회는 이 상한 안에 들어가지 않는다.
- 새 사용자는 엄격 `plan`의 금액 차단만으로 종료하지 않고, 명시적으로 승인된 요청 수 제한·가격 미확정 경로를 사용할 수 있다. 사전 비용을 보장하지 않으며 실제 차감과 미노출 상태를 구분해 기록한다.
- MonoGPT·Timely·ChatGPT 공통 흐름 및 별도 UI 지침.
- 엄격 사전 점검: 모델·추론·설정·요금·자료 검토·파일 해시.
- 로컬 init/record/status/report: 중복 방지, 미완료 대조, 조건 변경 거부, 기준별 평가·UX 이벤트 및 날짜 붙은 상세 PDF·XLSX·비용/품질 그래프 PDF. 서비스별 사용자 입력 원/크레딧으로 KRW 환산하며 원시 차감은 검증용 원장에 남긴다. 최종 출력에는 별도 패키지가 필요하다.
- 브라우저 전송·완료 관측 보조 모듈. 독립 브라우저 실행기는 아님.
- 첨부 전·전송 전·답변 후 비용 구분 및 공용 잔액 오염 규칙.
- Python 테스트 49개, 브라우저 JS 모의 테스트 11개 통과. 질문별 선그래프는 KRW 비용·품질 페이지와 별도 시간·수치 대조 페이지로 표시하고 미측정 지점의 선을 끊는다. 시간은 완료 관측 상한/구간을 보존하고 실패 응답을 성공 응답의 속도 점으로 표시하지 않는다. 기본 최종 저장 위치는 `~/AI-Benchmark-Reports/<run-id>/`, 변경은 `--output-dir`로 한다.
- 다른 사용자 브라우저 계정의 재현 검증은 아직 하지 않았다.
- 고정 코드 함수와 매출 XLSX 제한 검사. 범용 코드 샌드박스는 아님.

## 실제 관측됨

- 최종 `core-v2` GPT-6 Sol 보통: 8개 항목 × 3사 = 24회 응답 관측.
- 파일 생성은 1사 도구 한도 실패. 다른 2사는 다운로드·수식·재계산 검사 통과. 선택 모델과 소진내역 모델 충돌이 있어 파일 생성 묶음은 동일 모델 점수에서 분리.
- Claude Sonnet 5.5 낮음 요약 파일럿은 최종본에 포함하지 않았음.
- Claude 최종 세트 8개 항목을 MonoGPT·Timely에서 각각 실측했다. Timely 파일 생성 첫 한도 실패는 별도로 보존하고 충전 후 재시도 성공을 최종 칸에 넣었다. MonoGPT 파일은 다운로드됐으나 수식이 문자열이었다.
- 비개인 자료 검토와 3사 업로드 확인. 실제 답변과 최종 보고서는 Git 제외 경로에만 둔다. 원본 화면·중간자료는 개인 보관 방침에 따라 정리할 수 있다.
- 기존 최종 엑셀의 56개 실측 기록·평가를 사용해 원화 PDF·XLSX를 재출력했다. 별도 선그래프는 파일 생성 제외 49개 기록(모델별 공통 7문항)을 3페이지로 렌더링해 확인했다. 새 실측·재채점은 하지 않았으며 이전 파일럿은 섞지 않았다.
- Gemini 3.5 Flash-Lite 8개 항목을 MonoGPT·Timely에서 각각 실측했다. MonoGPT 기본 추론/Timely 보통은 사용자 지정 비대칭 조건의 탐색 비교다. 대화 초기화 오류와 전송 확인 불가 시도는 최종 칸과 별도 보존했다.
- UI 표시 조건의 서비스 경험 비교이며 실제 백엔드 버전 동등성은 미검증.

## 아직 완료하지 않음

- 최종본 기준 GPT 24회, Claude 16회, Gemini 16회로 56개 최종 기록 완료. ChatGPT의 Claude/Gemini 16개 칸은 모델 없음이다.
- Gemini의 엄격 동일 조건 비교가 필요하면 양쪽 추론 단계를 실제로 맞출 수 있는 후보를 별도로 확인한다.
- 다른 사용자 환경 재현. 현재 계정에서는 브라우저 보조 모듈을 최종 실측에 사용함.
- 블라인드 채점·반복 표본·실제 청구액과 환산율 대조·통계적 순위.
- 새 공용 3파일 출력의 다른 사용자 계정 재현. 현재 사용자의 기존 기록을 이용한 원화 출력·선그래프 렌더링은 확인했으며 새 계정의 UI 실측·품질 평가 과정은 별도로 검증해야 한다.

교육 항목 초기 관측 공백과 일부 긴 관측 간격은 속도 순위에서 제외한다. 공유 크레딧의 별도 내역이 섞이면 잔액 차이를 전부 테스트 비용으로 귀속하지 않는다. 크레딧 미노출은 무료가 아니다. 비대칭 추론 결과와 파일 생성 모델 불일치를 엄격 동일 모델 점수로 취급하지 않는다.
