# 작업 현황

## 구현됨

- 공통 8개 항목 각 1개 프롬프트와 모델별 2사/3사 비교 그룹.
- MonoGPT·Timely·ChatGPT 공통 흐름 및 별도 UI 지침.
- 엄격 사전 점검: 모델·추론·설정·요금·자료 검토·파일 해시.
- 로컬 init/record/status/report: 중복 방지, 미완료 대조, 조건 변경 거부, 원문 포함 HTML.
- 브라우저 전송·완료 관측 보조 모듈. 독립 브라우저 실행기는 아님.
- 첨부 전·전송 전·답변 후 비용 구분 및 공용 잔액 오염 규칙.
- Python 테스트 29개, 브라우저 JS 모의 테스트 8개 통과.
- 개인 파일·실측 결과를 제외한 새 복사본에서도 같은 37개 테스트 통과. 다른 사용자의 브라우저 계정 실측과는 별개다.
- 고정 코드 함수와 매출 XLSX 제한 검사. 범용 코드 샌드박스는 아님.

## 실제 관측됨

- 최종 `core-v2` GPT-6 Sol 보통: 8개 항목 × 3사 = 24회 응답 관측.
- 파일 생성은 1사 도구 한도 실패. 다른 2사는 다운로드·수식·재계산 검사 통과. 선택 모델과 소진내역 모델 충돌이 있어 파일 생성 묶음은 동일 모델 점수에서 분리.
- Claude Sonnet 5.5 낮음 요약 파일럿은 별도 보관하며 최종본에 포함하지 않음.
- Claude 최종 세트의 교육·기획을 2사에서 새로 실측했다. 나머지 항목은 진행 중이며 최종 통합 보고서에는 아직 반영하지 않음.
- 비개인 자료 검토와 3사 업로드 확인. 자료·원문·스크린샷은 Git 제외 경로에만 보관.
- 비공개 HTML·XLSX·PDF 3사 GPT 최종 보고서 생성·렌더 검증. `runs/final-core-v2/` 참조. 질문 8개만 사용하며 이전 파일럿을 혼합하지 않음.
- Gemini 3.8 Flash는 MonoGPT 추론 미노출 vs Timely 단계 선택으로 동일 조건 미확정. 유료 요청 보류.
- UI 표시 조건의 서비스 경험 비교이며 실제 백엔드 버전 동등성은 미검증.

## 아직 완료하지 않음

- 최종본 기준 전체 56개 모델·서비스·항목 조합 중 GPT 24회 및 Claude 4회 관측. Claude 나머지 12개, Gemini 16개가 남음.
- Gemini 공통 설정/대체 후보 실측.
- 다른 사용자 환경 재현. 현재 계정에서는 브라우저 보조 모듈을 최종 실측에 사용함.
- 블라인드 채점·반복 표본·원화 환산·통계적 순위.
- 공용 코드의 자동 XLSX/PDF 내보내기. 이번 출력은 환경별 도구로 별도 생성했고 공용 자동 출력은 HTML까지.
- 독립 무인 실행기는 없음. 공용 GitHub 배포와 개인 보고서 보관은 별도로 관리.

## 중요한 한계

교육 항목 초기 관측 공백과 일부 긴 관측 간격은 속도 순위에서 제외한다. 공유 크레딧의 별도 내역이 섞이면 잔액 차이를 전부 테스트 비용으로 귀속하지 않는다. 크레딧 미노출은 무료가 아니다. GPT 최종본을 전체 모델 완료라고 부르지 않는다.

재실행은 docs/RUNBOOK.md를 따른다.
