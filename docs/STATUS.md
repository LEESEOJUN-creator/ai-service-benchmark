# 작업 현황

## 구현됨

- 공통 8개 항목 각 1개 프롬프트와 모델별 2사/3사 비교 그룹.
- 기본 요청 상한 40회. 한 실행의 예약 상한도 최대 40회이며, 원화 예산·요청당 비용 확인 게이트는 유지한다. 3모델 전체 56회는 이 상한 안에 들어가지 않는다.
- 새 사용자는 엄격 `plan`의 금액 차단만으로 종료하지 않고, 명시적으로 승인된 요청 수 제한·가격 미확정 경로를 사용할 수 있다. 사전 비용을 보장하지 않으며 실제 차감과 미노출 상태를 구분해 기록한다.
- MonoGPT·Timely·ChatGPT 공통 흐름 및 별도 UI 지침.
- 엄격 사전 점검: 모델·추론·설정·요금·자료 검토·파일 해시.
- 로컬 init/record/status/report: 중복 방지, 미완료 대조, 조건 변경 거부, 기준별 평가·UX 이벤트 및 날짜 붙은 상세 PDF·XLSX·비용/품질 그래프 PDF. 서비스별 사용자 입력 원/크레딧으로 KRW 환산하며 원시 차감은 검증용 원장에 남긴다. 최종 출력에는 별도 패키지가 필요하다.
- 브라우저 전송·완료 관측 보조 모듈. 독립 브라우저 실행기는 아님.
- 첨부 전·전송 전·답변 후 비용 구분 및 공용 잔액 오염 규칙.
- Python 테스트 41개, 브라우저 JS 모의 테스트 11개 통과. 질문별 선그래프는 KRW 비용·품질·소요시간을 세 패널로 표시하고 미측정 지점의 선을 끊는다. 시간은 완료 관측 상한/구간을 보존하고 실패 응답을 성공 응답의 속도 점으로 표시하지 않는다. 기본 최종 저장 위치는 `~/AI-Benchmark-Reports/<run-id>/`, 변경은 `--output-dir`로 한다.
- 다른 사용자 브라우저 계정의 재현 검증은 아직 하지 않았다.
- 고정 코드 함수와 매출 XLSX 제한 검사. 범용 코드 샌드박스는 아님.

## 실제 관측됨

- 최종 `core-v2` GPT-6 Sol 보통: 8개 항목 × 3사 = 24회 응답 관측.
- 파일 생성은 1사 도구 한도 실패. 다른 2사는 다운로드·수식·재계산 검사 통과. 선택 모델과 소진내역 모델 충돌이 있어 파일 생성 묶음은 동일 모델 점수에서 분리.
- Claude Sonnet 5.5 낮음 요약 파일럿은 최종본에 포함하지 않았음.
- Claude 최종 세트 8개 항목을 MonoGPT·Timely에서 각각 실측했다. Timely 파일 생성 첫 한도 실패는 별도로 보존하고 충전 후 재시도 성공을 최종 칸에 넣었다. MonoGPT 파일은 다운로드됐으나 수식이 문자열이었다.
- 비개인 자료 검토와 3사 업로드 확인. 실제 답변과 최종 보고서는 Git 제외 경로에만 둔다. 원본 화면·중간자료는 개인 보관 방침에 따라 정리할 수 있다.
- 기존 최종 엑셀의 56개 실측 기록·평가를 사용해 원화 PDF·XLSX를 재출력했다. 별도 선그래프는 파일 생성 제외 49개 기록(모델별 공통 7문항)을 3페이지로 렌더링해 확인했다. 새 실측·재채점은 하지 않았으며 이전 파일럿은 섞지 않았다.
- Gemini 3.5 Flash-Lite 8개 항목을 MonoGPT·Timely에서 각각 실측했다. MonoGPT 기본 추론/Timely 보통은 사용자 지정 비대칭 조건의 탐색 비교다. 대화 초기화 오류와 전송 확인 불가 시도는 최종 칸과 별도 보존했다.
- UI 표시 조건의 서비스 경험 비교이며 실제 백엔드 버전 동등성은 미검증.

## 아직 완료하지 않음

- 최종본 기준 GPT 24회, Claude 16회, Gemini 16회로 56개 최종 기록 완료. ChatGPT의 Claude/Gemini 16개 칸은 모델 없음이다.
- Gemini의 엄격 동일 조건 비교가 필요하면 양쪽 추론 단계를 실제로 맞출 수 있는 후보를 별도로 확인한다.
- 다른 사용자 환경 재현. 현재 계정에서는 브라우저 보조 모듈을 최종 실측에 사용함.
- 블라인드 채점·반복 표본·실제 청구액과 환산율 대조·통계적 순위.
- 새 공용 3파일 출력의 다른 사용자 계정 재현. 현재 사용자의 기존 기록을 이용한 원화 출력·선그래프 렌더링은 확인했으며 새 계정의 UI 실측·품질 평가 과정은 별도로 검증해야 한다.
- 독립 무인 실행기는 없음. 공용 GitHub 배포와 개인 보고서 보관은 별도로 관리.

## 중요한 한계

교육 항목 초기 관측 공백과 일부 긴 관측 간격은 속도 순위에서 제외한다. 공유 크레딧의 별도 내역이 섞이면 잔액 차이를 전부 테스트 비용으로 귀속하지 않는다. 크레딧 미노출은 무료가 아니다. 비대칭 추론 결과와 파일 생성 모델 불일치를 엄격 동일 모델 점수로 취급하지 않는다.

재실행은 docs/RUNBOOK.md를 따른다.
