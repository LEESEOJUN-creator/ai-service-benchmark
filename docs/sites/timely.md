# Timely AI 조작 지침서

데스크톱 Chrome 한국어 화면 기준.

계정·요금제·모델·창 크기에 따라 UI가 다를 수 있다. 아래 위치는 고정 좌표가 아닌 탐색 힌트다. 접근성 이름과 현재 화면을 함께 확인하고, 이전 요소 ID를 재사용하지 않는다.

먼저 [공통 브라우저 흐름](../BROWSER-FLOW.md)과 [비교·측정 규약](../PROTOCOL.md)을 읽는다. 이 문서에는 계정명·잔액·실제 답변·스크린샷을 넣지 않는다.

## 버튼 위치 빠른 안내

| 작업 | 버튼 위치·경로 | 누른 뒤 확인할 것 |
|---|---|---|
| 접속 | https://timelyai.io/timely | 로그인된 계정의 채팅 화면인지 확인 |
| 사이드바 펼치기 | 화면 왼쪽 위 패널 아이콘 (`toggle minimized button`) | 새 채팅·대화 목록 표시 |
| 새 대화 | 사이드바 `새 채팅`; 접힌 상태는 왼쪽 세로 막대의 `+` (`new chat button`) | 기존 메시지가 없는 빈 입력 화면 |
| 모델 | 입력창 아래쪽 오른편 현재 모델명 (`model menu button`) | 선택 모델의 정확한 이름 |
| 추론 | 입력창 모델명 오른쪽 `추론 설정` | 선택 단계와 전송 후 요청별 적용 근거 |
| 웹 검색 | 입력창 왼쪽 `+` → `웹 검색` | 토글 상태 / 보라색 웹 검색 표시 |
| 리서치 | 입력창 왼쪽 `+` → `심층 리서치` | 일반 추론과 별도 기능임을 구분 |
| 문서 첨부 | 입력창 `+` (`upload button`) → `사진 및 파일 추가` | 첨부 이름·개수·완료 상태 |
| 이미지 첨부 | 문서와 같은 `사진 및 파일 추가` | 실제 이미지 미리보기·완료 상태 |
| 보내기 | 입력창 오른쪽 화살표 (`send button`) | 사용자 메시지가 정확히 1개 추가됨 |
| 크레딧 | 화면 오른쪽 위 `크레딧` | 상세 잔액·소진 내역·사용량 |
| 답변 복사 | 답변 바로 아래 복사 아이콘 (`message control button`, 내부 `copy`) | 복사된 답변 원문 |
| 답변 저장 | 답변 아래 다운로드 아이콘 (`message control button`, 내부 `download`) | 다운로드 형식·파일 존재 여부는 별도 검증 |
| 표 조작 | 표 위 `Copy table`, `Download table`, `View fullscreen` | 실제 다운로드와 파일 내용은 별도 검증 |

`message control button`처럼 이름이 중복되면 해당 답변 영역과 내부 아이콘을 함께 확인한다. 순서만 추측해 클릭하지 않는다.

## 확인 범위

- 확인: 기존 로그인 세션 접속, 새 채팅, 모델 메뉴, GPT-6 Sol 추론 메뉴, 첨부 메뉴, 웹 검색 선택·해제, 크레딧 사용 현황, 답변·표의 제어 버튼.
- 진입 버튼만 확인: 답변 다운로드, 표 다운로드·전체화면 등. 실제 파일 다운로드 성공을 보장하지 않는다.
- 미검증: 로그아웃 상태의 로그인/SSO/2차 인증, PNG/TXT 외 전체 확장자 제한, 타 사용자 계정 재현, 요청별 백엔드 실제 추론 수준. 생성 XLSX 다운로드·내용·재계산은 이번 계정에서 확인했다.
- 표시 모델명은 UI 선언이며 실제 공급자 백엔드 버전은 미검증이다.

## 상세 조작

### T1. 빈 대화부터 시작

1. 사이드바 위쪽 `새 채팅`을 누른다. 사이드바가 접혀 있으면 왼쪽 세로 막대의 `+`를 찾거나 맨 위 패널 버튼으로 펼친다. 이전 답변·캔버스가 열려 있으면 닫고, 새 대화의 빈 상태를 확인한다.
2. 입력창 안의 `+`는 첨부/도구 메뉴이므로 새 채팅 버튼과 구분한다.
3. 입력창과 대화 상태를 확인한다. 새 홈 화면에서 기본 모델이 다른 모델로 표시될 수 있으므로 이전 탭의 모델을 그대로 가정하지 않는다.
4. `/timely`에서 첫 질문을 보내면 `/timely/chat/...`로 이동할 수 있다. URL 변경만으로 생성 완료를 판단하지 않는다.

### T2. 모델과 추론

1. 입력창 아래쪽 오른편 현재 모델명을 누른다. 접근성 이름은 `model menu button`이다.
2. 모델 목록에서 `OpenAI` → `GPT-6 Sol`처럼 정확한 항목을 선택한다. 목록에 같은 모델이 추천 영역과 공급자 영역에 중복될 수 있다.
3. `Auto`와 `고비용` 표기 모델을 임의로 고르지 않는다. 상단 `모델별 특징 안내`는 외부 사용 설명 링크다.
4. 모델명 오른쪽 `추론 설정`을 연다. GPT-6 Sol에서 `낮음 / 보통 / 높음 / 매우 높음 / 최대`가 표시됐다. 다른 모델의 단계도 같을 것이라고 가정하지 않는다.
5. 선택 후 입력창 옆에 목표 단계가 표시되는지 확인한다.
6. 첫 전송 후 화면 이동으로 선택값이 바뀌면 전송 전·후 값을 따로 기록한다. 답변의 `GPT-6 Sol` 표시만으로 적용된 추론 수준까지 확인된 것은 아니다. 요청별 적용 수준을 확인하기 전에는 엄격 비교에서 제외한다.

### T3. 첨부·웹 검색·리서치

1. 입력창 왼쪽 아래 `+` (`upload button`)를 누른다.
2. 메뉴에는 `사진 및 파일 추가`, `그림 그리기`, `심층 리서치`, `웹 검색`, `스킬`, `커넥터`가 있다.
3. 파일과 이미지 모두 `사진 및 파일 추가`에서 시작한다. 표시된 안내는 `이미지·표·문서·코드 · 파일당 최대 50MB · 문서 최대 5개`였다. 이미지 개수·전체 확장자 제한은 이 안내만으로 확정하지 않는다.
4. `웹 검색`을 선택하면 메뉴에 선택 표시가 생기고, 닫은 뒤 입력창 아래에 보라색 `웹 검색` 표시가 나타난다.
5. 선택된 도구의 해제 버튼은 접근성 이름 `clear tool`이다. 클릭한 뒤 웹 검색 표시가 사라지는 것을 확인한다. 아이콘 위치는 현재 화면을 기준으로 찾는다.
6. `심층 리서치`는 추론 깊이와 별개다. 클릭 후 전체 설정 흐름·실행 비용은 아직 검증하지 않았으므로 활성화/실행을 추정하지 않는다.
7. 파일 선택은 승인된 비개인 자료로만 진행하고 실제 업로드 완료를 확인한다. PNG/TXT를 업로드하고 실제 분석 답변을 확인했다.

### T4. 크레딧과 결과 수집

1. 화면 오른쪽 위 `크레딧`을 눌러 `크레딧 사용 현황`을 연다.
2. 월별 `사용 한도 / 현재 사용량 / 남은 크레딧`과 `개인 크레딧 / 현재 사용량 / 남은 크레딧`을 각각 기록한다.
3. 전후 사용량 증가와 잔액 감소를 대조한다. 월 잔여와 개인 잔여를 더해 단일 잔액으로 취급하지 않는다. 계정 전체의 차감 우선순위는 단일 시험으로 일반화하지 않는다.
   월 잔여가 0으로 잘렸을 때도 사용량 수치가 증가할 수 있다. 이때 증가한 사용량을 기록하고 0차감으로 확정하지 않는다.
4. 답변 완료 표시와 전송 버튼의 생성 중/정지 상태 변화를 함께 확인한다. `2초 동안 생각함` 같은 표시는 전체 응답 시간이 아니다.
5. 답변 아래 복사·다운로드와 재생성·문제 신고를 구분한다. 표에는 별도 복사/다운로드/전체화면 버튼이 있다. 다운로드 버튼의 존재만으로 파일 생성 성공이라고 채점하지 않는다.

### Timely AI 측정 원칙 요약

- 입력창의 모델 메뉴 → 정확한 모델 → 바로 옆 추론 설정.
- 첫 요청 후 채팅 URL로 전환되면서 추론 선택창의 값이 유지되는지 반드시 확인한다. 결과의 적용 추론 수준이 확인되지 않으면 입력창의 전송 전/후 설정을 모두 기록하고 엄격한 비교를 보류한다.
- 우측 상단 크레딧 → 사용 현황. 월 사용 한도/사용량/잔여와 개인 크레딧/사용량/잔여를 분리한다. 두 잔액을 임의 합산하지 않는다.
- 답변의 생각한 시간 표시는 전체 응답 시간이 아니다.
## 추가 실측 주의점

- 입력창 +(`upload button`) → 사진 및 파일 추가 → 업로드 완료/등록된 파일 표시 확인. PNG와 TXT 경로를 실측했다.
- 같은 PNG가 업로드 후 `.webp`로 표시됐다. 원본 입력 해시는 같아도 서비스 내부 전처리가 다를 수 있다.
- TXT 업로드와 답변 요청의 차감이 분리 관측됐다. 월 한도 잔액·사용량·개인 크레딧을 함께 확인한다.
- 이번 Gemini 3.5 Flash-Lite에서는 보통을 선택했다. MonoGPT의 기본 추론과는 탐색 비교이며 엄격 동일 조건 결과로 합치지 않는다. Sonnet 5.5는 낮음/보통/높음/매우 높음/최대가 노출됐고 낮음은 전송 전후 유지됐다.
- 새 대화가 Solar Pro4로 초기화될 수 있으므로 모델을 매번 재선택한다.
- 긴 교육·기획·코드 답변은 캔버스로 열릴 수 있다. `캔버스 닫기`가 보이면 캔버스의 `복사`를 사용해 전체 본문을 수집한다. 채팅의 안내 문장만 최종 답변으로 저장하지 않는다.
- 파일 생성 도구 한도 초과 응답을 관측했다. 이때 답변 완료와 작업 성공을 분리하고, 실제 파일 없음·차감 발생·실패 사유를 기록한다. 한도 해제를 위해 결제하거나 반복 생성하지 않는다.
- 이번 계정에서 생성 파일 다운로드 후 시트·수식·재계산을 확인했다. 다운로드 관측 이벤트가 타임아웃이어도 파일이 실제 저장됐는지 먼저 확인한다. 보내기 클릭 후 질문이 대화에 나타나지 않은 경우에는 사용량·대화 기록을 대조하고 전송 여부를 미확정으로 기록한다. 0비용이나 서비스 오류로 단정하지 않는다.
