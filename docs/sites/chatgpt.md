# ChatGPT 조작 지침서

데스크톱 Chrome, 한국어 화면 기준. 계정·플랜·제공 시점에 따라 UI가 다를 수 있다.

먼저 [공통 브라우저 흐름](../BROWSER-FLOW.md)과 [측정 규약](../PROTOCOL.md)을 읽는다. 계정명·이메일·실제 잔액·답변·스크린샷은 Git에 넣지 않는다.

## 확인된 경로

| 작업 | 위치·이름 | 확인 기준 |
|---|---|---|
| 접속 | https://chatgpt.com/ | 로그인된 빈 채팅 화면; 계정명은 비공개 기록에도 최소화 |
| 새 대화 | 왼쪽 사이드바 `새 채팅` | 이전 대화 맥락 없는 화면 |
| 사이드바 | 왼쪽 위 `사이드바 숨기기` | 무관한 기록을 증거 캡처에서 제외 |
| 작업 모드 | 화면 위 `Chat` / `Work` | 선택 모드를 모델·추론과 별도로 기록 |
| 입력 | 중앙 `ChatGPT에게 물어보세요` | 전송 전 원문 대조 |
| 모델 메뉴 | 입력창 오른쪽 `ChatGPT 모델 선택` | 파워/추론 UI와 세부 모델 메뉴를 구분 |
| 세부 모델 | 모델 메뉴의 현재 모드명 오른쪽 화살표 | 현재 확인한 메뉴는 `Instant` 옆 화살표로 진입 |
| 첨부 진입 | 입력창 왼쪽 `파일 등 추가` → `사진 및 파일 추가` | PNG/TXT 실제 첨부·분석 확인 |

Chat 모드 초기 탐색에서는 Instant와 별도 모델 목록을 관측했다. 실제 비교는 아래 Work 절차로 진행했으므로 Chat의 모델·파워 UI를 그대로 재사용하지 않는다.

## 동일 조건 비교의 제한

- `GPT-6`를 다른 서비스의 `GPT-6 Sol`과 자동으로 동일시하지 않는다. `Instant`도 다른 서비스의 `low`와 임의 대응하지 않는다.
- Chat/Work 전환은 단순 이름 변경으로 취급하지 않는다. 모드, 도구, 모델, 추론, 첨부, 대화 경계를 별도로 고정한다.
- 모델별 참여 사이트를 분리한다. GPT 공통군은 3사, Gemini/Claude는 제공되는 2사끼리 비교한다. 미제공과 조건 미확인은 구분해서 제외 사유를 기록하고 0점 처리하지 않는다.
- 요청별 크레딧/사용량 메뉴와 과금 단위는 미확인이다. 월 구독료를 질문당 비용으로 임의 환산하지 않으며, 차감 표시가 없다고 0원으로 기록하지 않는다.

## Chat과 Work

공식 안내는 Chat을 질문·대화·초안 다듬기에, Work를 여러 단계와 도구를 활용해 검토 가능한 결과물을 완성하는 작업에 구분해 설명한다. 둘 다 플러그인을 사용할 수 있으므로 Chat은 도구를 전혀 못 쓰는 모드라고 설명하지 않는다. Work가 항상 더 정확하거나 같은 비용·속도라고 가정하지 않는다.

출처: [사용 모드 안내](https://learn.chatgpt.com/docs/use-chatgpt), [Chat or Work 안내](https://learn.chatgpt.com/training/walkthroughs/getting-started).

## 아직 미검증

API 추론 수준의 정확한 대응, 요청별 비용, 로그아웃 상태 로그인/SSO/추가 인증, 타 사용자 재현은 미검증이다. Work 모델 선택·질문·답변·PNG/TXT 업로드 및 생성 XLSX 다운로드·수식·재계산은 검증했다.

## 추가 검증: Work

- 상단 `Work` 선택 → 입력창의 `ChatGPT 모델 선택` → 모델명 아래 화살표와 파워 슬라이더.
- Work 화면에서 GPT-6 Sol과 Light/Medium 파워를 확인했다. Medium 선택 후 실제 질문 전송과 답변 완료를 확인했으며 완료 후에도 Medium이 유지됐다.
- `빠른 모드 활성화`는 별도 토글이다. 기본 비교에서 끈 상태를 기록한다. 고비용·자동 모델 변경으로 대체하지 않는다.
- 입력창 아래 `플러그인` 메뉴에서 연결 유무를 확인한다. 연결을 새로 설치하거나 권한을 확장하지 않는다.
- 완료는 `응답이 완료되었습니다`, 중지 버튼 소멸, 답변 복사 버튼 등으로 확인한다. 생성 중 부분 표를 최종 답변으로 채점하지 않는다.
- `복사`는 답변 전체, `표 복사`는 표만 복사한다. 원문 보존에는 답변 전체 복사를 쓴다.
- 이번 검증은 **ChatGPT Work**다. Chat의 Instant와 Work의 Medium을 같은 실행 모드로 합치지 않는다. 서비스 도구·내부 지침은 통제할 수 없어 순수 모델 벤치마크가 아닌 서비스 실사용 비교다.
- 요청별 비용과 응답별 실제 백엔드 버전/effort는 여전히 미검증이다. 개인 결과는 `runs/`에만 보관한다.

공식 근거: [모델과 추론 선택](https://learn.chatgpt.com/docs/models?surface=web). 이 문서는 GPT-6 Sol이 Work/Codex에서 제공되며 Chat과 구분됨을 설명한다. 계정별 실제 메뉴는 매번 확인한다.
## 추가 실측 주의점

- Work 새 대화의 기본 모델이 GPT-6.1 Sol로 돌아가는 현상을 확인했다. Medium 표시만 확인하지 말고 모델 선택 하위 목록에서 GPT-6 Sol을 재선택한다.
- 파일 등 추가 → 사진 및 파일 추가 → 컴퓨터에서 업로드 경로로 PNG/TXT 첨부를 검증했다. 진행 표시가 사라지고 파일명이 남는지 확인한다.
- Chrome 확장의 파일 URL 접근이 꺼져 있으면 업로드가 실패할 수 있다. 오류 시 지원 문서를 따르고 사용자에게 해당 권한을 직접 허용하도록 요청한다. 보안 설정을 우회하지 않는다.
- 새 대화에도 이전 `응답이 완료되었습니다` 상태가 남을 수 있다. 현재 프롬프트와 최종 답변 복사 버튼, 중지 버튼 소멸을 함께 확인한다.
- 요청별 차감 수치를 관측하지 못한 경우 null로 기록한다. Plus/정액제라는 이유로 요청 비용을 0으로 처리하지 않는다.
- 생성 XLSX 링크를 내려받아 실제 파일을 검사했다. 다운로드 이벤트 타임아웃만으로 실패라고 단정하지 않고 승인된 다운로드 폴더에서 방금 생긴 정확한 파일을 확인한다. 생성 재시도는 자동으로 하지 않는다.
