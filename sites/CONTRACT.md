# 사이트 연결 규격

현재 세 JSON 프로필은 미검증 상태이며 실행 모듈이 아닙니다. 실제 DOM 선택자·좌표·메뉴 이름은 화면 확인 전에 만들지 않습니다.

구현할 동작:

| 동작 | 반환할 근거 |
|---|---|
| 로그인 확인 | 로그인 여부, 계정 요금제, 추가 인증 필요 여부 |
| 모델 목록 확인 | 실제 표시 모델명, 추론 옵션, 날짜와 화면 근거 |
| 모델/설정 선택 | 선택 후 재확인 결과 |
| 새 대화 생성 | 새 대화 확인, 대화 ID/URL이 노출되면 기록 |
| 잔액 읽기 | 메뉴 단계, 잔액 문자열, 단위, 정밀도, 시각, 화면 근거 |
| 첨부 | 지원 형식, 파일명, 업로드 완료 확인 |
| 입력/전송 | 실제 입력 내용, 한 번만 전송됐는지 여부, 전송 시각 |
| 응답 수집 | 최초/완료 관측, 원문, 생성 파일, 오류 |

검증 후 `models`에 후보 ID를 키로 다음 구조를 등록합니다. 아래 값은 스키마 설명이며 모델 확인 자료가 아닙니다.

```json
{
  "verified": true,
  "canonical_model": "확인된 공통 모델 ID",
  "version": "확인된 버전",
  "reasoning": {"mode": "fixed", "level": "확인된 공통 수준", "budget_tokens": null},
  "feature_settings": {"web_search": false, "memory": false},
  "evidence_scope": "ui_declared",
  "evidence": "확인 일자와 문서 또는 로컬 증거 위치",
  "max_request_cost_krw": null
}
```

`max_request_cost_krw`는 입력 누적·출력 상한·첨부·도구 요금을 고려한 보수적 상한입니다. 실제 계정에서 상한을 산정할 수 없다면 비워 두고 실행을 차단합니다. 프로필의 `browser_flow_verified`는 소규모 실제 검증 후에만 true로 바꿉니다.
