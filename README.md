# AI Service Benchmark

동일 모델·동일 추론 수준·동일 입력으로 AI 웹 서비스를 비교하는 재사용 가능한 프로젝트.
초기 대상은 MonoGPT, Timely AI, Works AI이며, 다른 사용자가 본인 계정과 연결된 브라우저로 재실행하는 것을 목표로 합니다.

## 현재 상태

**초기 구조와 실행 전 점검만 구현됐습니다.** 로그인, 브라우저 조작, 실측, 채점, HTML 보고서 생성은 아직 구현·검증되지 않았습니다. `plan`은 브라우저에 접속하거나 크레딧을 사용하지 않습니다. 사이트 URL·접속 지침·계정은 추후 연결합니다.

Python 3.9 이상과 Git만 있으면 초기 점검을 실행할 수 있습니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
python3 -m benchmark plan
python3 -m unittest discover -s tests -v
```

기본 설정은 미확정 상태이므로 `plan`은 차단 사유를 출력하고 종료 코드 2를 반환합니다. 이것은 의도된 동작입니다. 점검을 통과해도 브라우저 실행 기능이 구현된 것은 아닙니다.

## 구성

```text
AGENTS.md                Codex 실행 지침과 정직한 결과 기록 원칙
config/benchmark.json    서비스, 모델 후보, 반복 횟수, 예산
sites/                  사이트별 확인 결과와 연결 규격
cases/smoke.json         공통 프롬프트, 대화 순서, 기대 결과
fixtures/manifest.json  테스트 파일의 승인·해시·자료 분류
prompts/start.md         다른 사용자가 입력할 시작 프롬프트
benchmark/              사전 점검과 측정값 계산 코드
tests/                  조건 일치와 비용 계산 검증
docs/                   실행 흐름, 평가 기준, 작업 현황
local/                  로컬 설정·개인 계정용 정보 (Git 제외)
runs/                   실제 답변·스크린샷·보고서 (Git 제외)
```

## 비교 조건

- 모델 후보: Gemini 1종, 사용자 표현 `GPT 6 Sol`, `Claude Sonnet 5.5`. 실제 지원 모델·버전·가격은 아직 미확인입니다.
- 비싼 최상위 모델은 기본 대상에 넣지 않습니다. 다른 후보를 선택하더라도 같은 비교 묶음의 모든 사이트에서 동일 모델·추론 설정을 확인해야 합니다.
- `Auto` 라우팅이나 `Eco` 같은 서비스 고유 모드를 같은 모델이라고 추정하지 않습니다.
- 추론 수준이 미공개이거나 다른 사이트와 대응되지 않으면 엄격한 비교를 차단합니다.
- 한 테스트의 프롬프트·파일 바이트·후속 질문 순서는 모든 사이트에 동일하게 적용합니다.
- 파일은 사용자의 자료 중 업무용·공개·비개인 자료인지 검토한 뒤 등록합니다. 개인 문서나 개인 사진은 제외합니다. 현재는 파일을 선정하거나 업로드하지 않았습니다.
- 예산은 아직 정하지 않았습니다. 자동 충전·추가 결제는 하지 않습니다.

## 다음 작업

1. 세 사이트의 정확한 URL과 사용 지침을 연결하고 로그인 절차를 확인합니다.
2. 공통 모델·추론 설정·크레딧 표시와 차감 지연을 실제 UI에서 확인합니다.
3. 비개인 테스트 파일을 선정하고 내용·해시·업로드 대상을 확인합니다.
4. 한 모델·소수 테스트로 입력, 비용, 시간, 결과 수집의 정확성을 검증합니다.
5. 반복 실행·평가·HTML 및 표 형식 보고서 생성 기능을 구현합니다.
6. 다른 사용자 환경에서 시작 안내만으로 재실행되는지 검증합니다.

GitHub 원격 저장소는 아직 없습니다. 실제 결과를 배포할 때는 계정 정보와 민감한 화면을 검토한 사본만 포함해야 합니다.
