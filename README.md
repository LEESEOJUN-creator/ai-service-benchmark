# AI Service Benchmark

동일 모델·동일 추론 수준·동일 입력으로 AI 웹 서비스를 비교하는 재사용 가능한 프로젝트.
현재 대상은 MonoGPT, Timely AI, ChatGPT이며, 다른 사용자가 본인 계정과 연결된 브라우저로 재실행하는 것을 목표로 합니다. Works AI는 사용자 요청으로 비교 대상에서 제외했습니다.

## 현재 상태

**에이전트 실행형 키트입니다.** 최종 버전 `core-v2`의 8개 공통 프롬프트, 3사 UI 지침, 엄격 사전 점검, 중복 전송 방지 실행 기록, 오프라인 HTML 보고서, 브라우저 전송·완료 관측 보조 모듈을 제공합니다. 시작 순서는 [재사용 실행 절차](docs/RUNBOOK.md)에 있습니다. Python만으로 로그인·모델 선택까지 수행하는 독립 무인 실행기는 아닙니다. 현재 계정에서 GPT 24회, Claude 16회, Gemini 16회로 총 56개 최종 칸을 실측했으며 다른 사용자 환경의 재현 검증은 남아 있습니다. Gemini는 사용자 승인에 따른 비대칭 추론 설정의 참고 비교입니다.

Python 3.9 이상과 Git만 있으면 초기 점검을 실행할 수 있습니다. 별도 패키지 설치는 필요하지 않습니다.

```sh
python3 -m benchmark plan
python3 -m unittest discover -s tests -v
```

기본 설정은 계정별 모델 근거·요금이 미확정이므로 `plan`은 차단 사유와 종료 코드 2를 반환합니다. 이는 의도된 동작입니다. 가격 상한 미확정 파일럿은 별도의 범위 승인과 기록 규약을 따르며, 엄격 점검 통과로 위장하지 않습니다. 모든 Python 명령은 로컬 기록만 다루며 크레딧을 쓰지 않습니다.

```sh
python3 -m benchmark init --run pilot
python3 -m benchmark status --run pilot
python3 -m benchmark report --run pilot
```

`record --event`의 필드는 RUNBOOK을 확인하세요. PDF/XLSX는 해당 환경의 문서 도구로 `runs/`에 생성하고 렌더 검증합니다. 공용 Python 자동 내보내기는 현재 HTML까지입니다.

## 구성

사이트를 직접 조작할 때는 [공통 브라우저 흐름](docs/BROWSER-FLOW.md)을 먼저 읽고, 실행 대상의 [MonoGPT 지침](docs/sites/monogpt.md), [Timely AI 지침](docs/sites/timely.md), [ChatGPT 지침](docs/sites/chatgpt.md)을 읽으세요. 공통 문서는 진행 순서·예외 처리, 개별 문서는 버튼 위치·모델·추론·검색·첨부·크레딧·결과 수집을 담당합니다.

```text
AGENTS.md                Codex 실행 지침과 정직한 결과 기록 원칙
config/benchmark.json    서비스, 모델 후보, 반복 횟수, 예산
sites/                  사이트별 확인 결과와 연결 규격
cases/core.json          최종 공통 프롬프트 8개와 평가 기준
fixtures/manifest.json  테스트 파일의 승인·해시·자료 분류
prompts/start.md         다른 사용자가 입력할 시작 프롬프트
benchmark/              사전 점검과 측정값 계산 코드
tests/                  조건 일치와 비용 계산 검증
docs/                   실행 흐름, 평가 기준, 작업 현황
docs/sites/             사이트별 버튼 위치와 조작 지침
local/                  로컬 설정·개인 계정용 정보 (Git 제외)
runs/                   실제 답변·스크린샷·보고서 (Git 제외)
```

## 비교 조건

- 모델 후보: Gemini 저비용 1종, GPT-6 Sol, Claude Sonnet 5.5. UI에서 후보를 확인했더라도 다른 계정의 지원·가격·설정은 다시 확인합니다.
- 비싼 최상위 모델은 기본 대상에 넣지 않습니다. 다른 후보를 선택하더라도 같은 비교 묶음의 모든 사이트에서 동일 모델·추론 설정을 확인해야 합니다.
- `Auto` 라우팅이나 `Eco` 같은 서비스 고유 모드를 같은 모델이라고 추정하지 않습니다.
- ChatGPT의 Chat/Work는 별도 실행 조건입니다. UI 모델 이름이나 추론 표현이 다른 서비스와 대응되지 않으면 동일 조건으로 확정하지 않습니다. ChatGPT가 포함된 3사 공통 후보는 다시 확인하며 Gemini/Claude를 지원한다고 가정하지 않습니다.
- 추론 수준이 미공개이거나 다른 사이트와 대응되지 않으면 엄격한 비교를 차단합니다.
- 한 테스트의 프롬프트·파일 바이트·후속 질문 순서는 모든 사이트에 동일하게 적용합니다.
- 파일은 사용자의 자료 중 업무용·공개·비개인 자료인지 검토한 뒤 등록합니다. 개인 문서나 개인 사진은 제외합니다. 이번 계정에서는 검토한 이미지·텍스트를 3사에 업로드했으며, 파일과 검토 기록은 `fixtures/local/`에만 있습니다. 다른 사용자는 자신의 검토 자료를 등록합니다.
- 예산은 아직 정하지 않았습니다. 자동 충전·추가 결제는 하지 않습니다.

## 다음 작업

다른 사람에게 전달하는 순서는 [HANDOFF](docs/HANDOFF.md)를 확인하세요. 로컬 테스트 40개가 통과했지만 다른 사용자의 실제 계정 실행은 아직 미검증입니다.

1. 다른 사용자 계정·환경에서 재현 검증.
2. Gemini의 엄격 동일 조건 비교가 필요하면 양쪽 추론 설정을 실제로 맞출 수 있는지 별도로 확인. 이번 참고 비교의 설정을 기본값으로 재사용하지 않음.
3. Claude·Gemini의 파일 생성과 실패·재시도 결과를 실제 다운로드 및 사용 내역과 함께 재검증.
4. 개인 최종 통합 PDF·XLSX·HTML은 `runs/final-comparison/`에 보관. GPT 1건은 도구 한도 실패했고, Claude 1건은 파일 수식이 문자열이었으며, 일부 파일 생성은 선택 모델과 사용 내역 모델이 달라 모델 비교에서 분리했습니다.
