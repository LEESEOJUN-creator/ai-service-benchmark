# AI Service Benchmark

동일 모델·동일 추론 수준·동일 입력으로 AI 웹 서비스를 비교하는 재사용 가능한 프로젝트.
현재 대상은 MonoGPT, Timely AI, ChatGPT이며, 다른 사용자가 본인 계정과 연결된 브라우저로 재실행하는 것을 목표로 합니다.

## 현재 상태

**에이전트 실행형 키트입니다.** 최종 버전 `core-v2`의 8개 공통 프롬프트, 3사 UI 지침, 엄격 사전 점검, 중복 전송 방지 실행 기록, 기준별 근거 평가와 날짜가 붙은 비공개 상세 PDF·XLSX·그래프 PDF 출력, 브라우저 전송·완료 관측 보조 모듈을 제공합니다. 시작 순서는 [재사용 실행 절차](docs/RUNBOOK.md)에 있습니다. Python만으로 로그인·모델 선택까지 수행하는 독립 무인 실행기는 아닙니다. 현재 계정에서 GPT 24회, Claude 16회, Gemini 16회로 총 56개 최종 칸을 실측했으며 다른 사용자 환경의 재현 검증은 남아 있습니다. Gemini는 사용자 승인에 따른 비대칭 추론 설정의 참고 비교입니다.

Python 3.9 이상과 Git만 있으면 초기 점검을 실행할 수 있습니다. PDF·XLSX·그래프 출력에만 `requirements-report.txt`의 패키지가 필요합니다.

```sh
python3 -m benchmark plan
python3 -m unittest discover -s tests -v
```

기본 설정은 계정별 모델 근거·요금이 미확정이므로 `plan`은 차단 사유와 종료 코드 2를 반환합니다. 이는 **엄격 금액 상한 계획이 준비되지 않았다는 뜻**이지, 가격 미확정 테스트가 항상 금지된다는 뜻은 아닙니다. 사용자가 금액 상한 없이 고정된 요청 수의 테스트를 명시적으로 승인한 경우 [RUNBOOK](docs/RUNBOOK.md)의 요청 수 제한 경로를 사용합니다. 요청 상한 40회는 자동 승인이나 목표 횟수가 아니며, 차감 관측·재시도 0회·추가 결제 금지를 유지합니다. 다른 모델·입력·파일 검토 차단 사유는 별도로 해결합니다. 모든 Python 명령은 로컬 기록만 다루며 크레딧을 쓰지 않습니다.

```sh
python3 -m benchmark init --run pilot
python3 -m benchmark status --run pilot
python3 -m pip install -r requirements-report.txt
# config/credit-rates.example.json을 복사해 local/credit-rates.json에 본인 계정의 환산율 입력
python3 -m benchmark report --run pilot --rates local/credit-rates.json
```

`record --event`의 필드는 RUNBOOK을 확인하세요. 성공 답변마다 5개 기준의 `assessment` 기록이 있어야 최종 출력됩니다. `report`는 `~/AI-Benchmark-Reports/<run-id>/`에 날짜가 붙은 상세 PDF, XLSX, 질문별 비용·품질 선그래프 PDF **세 파일**을 생성하고 기존 최종 파일을 덮어쓰지 않습니다. 크레딧 차감이 있으면 `--rates`에 서비스별 1크레딧당 원화 환산율이 필요합니다. 원시 크레딧은 XLSX 검증 원장에만 남기고 비교 표시 비용은 KRW로 바꿉니다. 저장 위치를 바꾸려면 `--output-dir "원하는 폴더"`를 사용하세요. 원본 실행 기록은 별도로 보관하며 사용자가 명시적으로 정리할 때만 삭제합니다.

## 폴더 안내

다른 사용자는 [시작 프롬프트](prompts/start.md)를 Codex에 입력하고 [실행 순서](docs/RUNBOOK.md)를 따르면 됩니다. 사이트를 직접 조작할 때는 [공통 브라우저 흐름](docs/BROWSER-FLOW.md)과 해당 사이트의 버튼 안내서를 읽습니다.

| 경로 | 담긴 내용 | 일반 사용자가 할 일 |
|---|---|---|
| `prompts/start.md` | Codex에게 전달할 시작 지시문 | 처음 실행할 때 사용 |
| `cases/core.json` | 최종 비교 질문 8개와 항목별 평가 기준 | 세 사이트에 같은 원문 사용 |
| `cases/smoke.json` | 연결·코드 점검용 짧은 예시 | 최종 보고서에는 사용하지 않음 |
| `docs/` | 실행 절차, 평가 방법, 측정 원칙, 현재 상태 | 필요한 안내서 읽기 |
| `docs/sites/` | MonoGPT·Timely·ChatGPT의 버튼 위치와 확인 방법 | 해당 사이트를 조작할 때 읽기 |
| `sites/` | 사이트별 설정 JSON과 신규 사이트 연결 규격 | 계정별 지원 모델·비용을 확인하고 갱신. 실행 코드 아님 |
| `config/` | 실행 대상·모델 후보·요청 상한의 기본 설정과 템플릿 | 자기 계정에 맞게 검증한 뒤 로컬 설정 사용 |
| `fixtures/` | 이미지·파일 입력의 검토/해시 기록 양식 | 비개인 자료를 검토해 `fixtures/local/`에 등록 |
| `browser/` | Codex 브라우저의 전송·완료 관측·모델 설정 보조 코드 | 보통 직접 수정하지 않음. UI가 바뀌면 재확인 |
| `benchmark/` | 사전 점검, 실행 기록, 원화 환산, PDF·XLSX·그래프 출력 코드 | Python 명령으로 사용 |
| `tests/` | 조건·기록·브라우저 보조 코드의 회귀 검사 | 변경 후 실행 |
| `AGENTS.md` | Codex가 지킬 프로젝트 규칙 | 에이전트가 읽음 |

`sites/`의 JSON은 기계가 읽는 설정이고 `docs/sites/`의 Markdown은 사람이 읽는 조작 안내서입니다.

`local/`은 계정별 설정, `fixtures/local/`은 개인이 검토한 첨부 자료, `runs/`는 실제 답변·스크린샷·보고서를 두는 자리입니다. 이 세 경로는 Git에서 제외됩니다. 사이트 로그인 정보도 공용 파일에 넣지 않습니다.

## 비교 조건

- 모델 후보: Gemini 저비용 1종, GPT-6 Sol, Claude Sonnet 5.5. UI에서 후보를 확인했더라도 다른 계정의 지원·가격·설정은 다시 확인합니다.
- 비싼 최상위 모델은 기본 대상에 넣지 않습니다. 다른 후보를 선택하더라도 같은 비교 묶음의 모든 사이트에서 동일 모델·추론 설정을 확인해야 합니다.
- `Auto` 라우팅이나 `Eco` 같은 서비스 고유 모드를 같은 모델이라고 추정하지 않습니다.
- ChatGPT의 Chat/Work는 별도 실행 조건입니다. UI 모델 이름이나 추론 표현이 다른 서비스와 대응되지 않으면 동일 조건으로 확정하지 않습니다. ChatGPT가 포함된 3사 공통 후보는 다시 확인하며 Gemini/Claude를 지원한다고 가정하지 않습니다.
- 추론 수준이 미공개이거나 다른 사이트와 대응되지 않으면 엄격한 비교를 차단합니다.
- 한 테스트의 프롬프트·파일 바이트·후속 질문 순서는 모든 사이트에 동일하게 적용합니다.
- 파일은 사용자의 자료 중 업무용·공개·비개인 자료인지 검토한 뒤 등록합니다. 개인 문서나 개인 사진은 제외합니다. 이번 계정에서는 검토한 이미지·텍스트를 3사에 업로드했으며, 파일과 검토 기록은 `fixtures/local/`에만 있습니다. 다른 사용자는 자신의 검토 자료를 등록합니다.
- 예산은 아직 정하지 않았습니다. 자동 충전·추가 결제는 하지 않습니다.

## 다음 작업

다른 사람에게 전달하는 순서는 [HANDOFF](docs/HANDOFF.md)를 확인하세요. 로컬 테스트 43개가 통과했지만 다른 사용자의 실제 계정 실행은 아직 미검증입니다.

1. 다른 사용자 계정·환경에서 재현 검증.
2. Gemini의 엄격 동일 조건 비교가 필요하면 양쪽 추론 설정을 실제로 맞출 수 있는지 별도로 확인. 이번 참고 비교의 설정을 기본값으로 재사용하지 않음.
3. Claude·Gemini의 파일 생성과 실패·재시도 결과를 실제 다운로드 및 사용 내역과 함께 재검증.
4. 개인 최종 통합 자료는 공용 Git에 포함하지 않습니다. GPT 1건은 도구 한도 실패했고, Claude 1건은 파일 수식이 문자열이었으며, 일부 파일 생성은 선택 모델과 사용 내역 모델이 달라 모델 비교에서 분리했습니다.
