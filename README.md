# AI Service Benchmark

MonoGPT·Timely AI·ChatGPT를 동일 모델·추론·입력 조건으로 비교하는 에이전트 실행형 키트입니다. 공통 질문, 사이트 조작 지침, 시간·비용 기록, 답변 평가, 보고서 출력을 제공합니다. Python만으로 로그인부터 실행하는 독립 무인 프로그램은 아니며, 실제 조작이 가능한 브라우저 도구가 필요합니다.

## 시작하기

1. 이 저장소를 작업 폴더로 열고 [시작 프롬프트](prompts/start.md)를 새 세션에 전달합니다.
2. 에이전트는 [실행 안내](docs/REPRODUCIBLE-RUN.md)를 따라 준비 → 실측 → 평가 → 보고서 검증을 진행합니다. 이전 대화나 개인 보고서는 필요하지 않습니다.
3. 사용자는 사이트·로그인 상태, 실행할 요청 범위, 서비스별 원/크레딧을 제공합니다. 이미 제공한 정보는 반복해서 묻지 않습니다.

기본 계획은 **GPT 8문항×3사=24회, Claude·Gemini 각각 4문항×2사=8회씩, 총 40회**입니다. 실제 지원 모델·설정과 첨부 자료를 확인한 뒤 승인된 범위에서 실행합니다. 추론만 맞출 수 없으면 승인된 자동 참고 비교 또는 한 번 확인 경로를 사용하며, 엄격 비교와 분리합니다.

Python 3.9 이상이 필요합니다. PDF·엑셀 출력에는 `requirements-report.txt`, 브라우저 보조 코드의 회귀 검사에는 Node가 필요합니다. 계정별 요금이 미확정이면 `plan`이 종료 코드 2를 반환할 수 있습니다. 이것만으로 전체 실행을 중단하지 말고 [금액 상한 없는 요청 수 제한 경로](docs/RUNBOOK.md#시작)를 확인합니다. 승인 없는 전송·자동 충전·추가 결제는 하지 않습니다.

## 받는 결과물

기본 전달 위치는 `~/AI-Benchmark-Reports/<run-id>/`이며, `--output-dir`로 바꿀 수 있습니다. 날짜가 붙은 최종 **3파일**을 생성하고 기존 파일을 덮어쓰지 않습니다.

- 상세 PDF: 모델별 요약, 서비스 간 차이, 답변의 강점·한계·실무 영향과 채점 근거, UX.
- 엑셀: 모델별 요약, 서비스 비교, 기준별 평가, 실측 원장, 답변 원문, 사용 경험.
- 그래프 PDF: 모델별 비용(KRW)·품질 선그래프와 별도 소요시간·수치 대조. 파일 생성·모델 전환은 별도 기능 결과.

비용은 사용자가 입력한 원/크레딧으로 환산합니다. 시간은 외부 완료 관측 상한/구간이며 정밀 서버 생성시간이 아닙니다. 모델 없음·미측정은 0으로 채우지 않습니다. UI 표시 조건이 같아도 실제 백엔드 동일성은 미검증입니다.

## 안내서 역할

| 문서 | 용도 |
|---|---|
| [AGENTS.md](AGENTS.md) | 에이전트가 지킬 비교·개인정보·완료 원칙 |
| [실행 안내](docs/REPRODUCIBLE-RUN.md) | 처음부터 끝까지 따라갈 기본 순서와 전달 전 체크리스트 |
| [설정·명령·기록 참고](docs/RUNBOOK.md) | 실행 설정, 요청 수 승인, 이벤트 필드, 원화 환산율 |
| [브라우저 조작](docs/BROWSER-FLOW.md) / [사이트별 지침](docs/sites/) | UI 확인, 버튼 위치, 예외 처리 |
| [측정 규약](docs/PROTOCOL.md) / [평가 기준](docs/EVALUATION.md) | 비교 가능성·비용·시간의 의미, 채점과 UX 기준 |
| [예외·보조 모듈 참고](docs/EXECUTION-RELIABILITY.md) | 추론 불일치 처리, 선택적 Playwright 보조 코드 |
| [다른 사용자에게 전달](docs/HANDOFF.md) | 준비물과 배포 시 포함/제외 |

기본 측정은 영속 CLI 타이머, 기록과 출력은 공용 코드 한 경로를 사용합니다. 실행마다 타이머·기록기·보고서 빌더를 새로 만들지 않습니다. [가상 평가 예시](examples/review-example.json)는 설명 수준을 보여주는 자료이지 재사용할 실측 결과가 아닙니다.

## 폴더 안내

| 경로 | 내용 |
|---|---|
| `prompts/` | 시작 지시문 |
| `cases/` | 최종 질문 `core.json` 8종과 개발 점검용 `smoke.json` |
| `docs/`, `docs/sites/` | 공통 안내서와 사이트별 조작법 |
| `sites/` | 사이트별 설정 JSON과 신규 사이트 연결 규격. 실행 코드 아님 |
| `config/`, `fixtures/` | 공용 설정·환산율 템플릿과 첨부 검토/해시 양식 |
| `examples/` | 개인정보 없는 가상 평가 예시 |
| `browser/`, `benchmark/` | 브라우저 보조 코드와 측정·기록·보고서 코드 |
| `tests/` | 회귀 검사. 실제 사이트 로그인·결제는 수행하지 않음 |

개인 설정 `local/`, 인증 `.auth/`, 원본 `runs/`, 검토한 첨부 `fixtures/local/`은 Git 제외입니다. 계정·쿠키·실제 답변·스크린샷·개인 보고서를 올리지 않으며 원본은 자동 삭제하지 않습니다.

## 개발 참고

최신 검증 범위와 과거 변경 이력은 [STATUS](docs/STATUS.md), 구현과 실측의 구분은 [IMPLEMENTATION-STATUS](docs/IMPLEMENTATION-STATUS.md)에 있습니다. 과거 계정의 승인·설정·결과를 새 실행에 복사하지 않습니다. 자동테스트 통과는 다른 사용자 계정에서의 실제 재현 성공을 뜻하지 않습니다.
